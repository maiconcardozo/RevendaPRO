# Instrucoes para agentes

1. Leia `context.md`, esta instrucao e os documentos de arquitetura antes de editar codigo.
2. Depois leia o repositorio `Arquitetura.Global` e siga seus padroes.
3. Preserve o dominio em portugues brasileiro.
4. Nao introduza dependencias entre `Application` e `Infrastructure`.
5. Documente toda decisao estrutural em ADR.
6. Nao implemente integracao FIPE, anexos ou persistencia real sem decisao registrada.
